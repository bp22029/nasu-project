# 旅診断キャラクター — デザイン引継ぎ書（Claude Design 用）

> このドキュメントは、**#NASU（ハッシュナス）** の新機能「**那須旅診断**」で使う **16タイプのキャラクターイラスト**を制作するための引継ぎ書です。
> 制作は Claude Design に依頼します。本書だけで、アプリの世界観・16タイプの性格・線画の作法・納品仕様がわかるように書いています。
> 配色・書体・線の作法・グレイン値などは、実際のアプリのソースコード（リポジトリ）に照らして検証済みの値です。**ここに書いた数値をそのまま使えば、既存ページに馴染みます。**

---

## 0. まず結論（依頼の要点）

- **作るもの**: 旅のタイプを表す **キャラクターイラスト 16種**。
- **トーン**: **深緑モノトーンの線画**（生成りの紙＋森の緑の世界観に合わせる）。
- **形式**: **SVG・背景透過**。小さく置いても拡大しても破綻しないこと。
- **題材は未確定**: 「人物 / オリジナルのマスコット / 動物」の **3案を試作して比較**したい（→ §6）。進め方は二段階。①各案を数体ずつ試作 → 1案に決定。②決定案で **共通素体（モデルシート）を先に固定** → そこから差分で16種を派生（→ §6 フェーズ2）。
- **16種の統一感が最重要**: 線の太さ・顔の描き方・塗りの量・画角・キャラの基準スケールを全16種でそろえる。**性格差は「小物・表情」に加えて「ポーズ・姿勢」でも出す**（小サイズで見分けるために姿勢の差は積極的に使う。詳細は §5）。

## 1. このイラストが使われる場所（機能の文脈）

#NASU は「Instagram で"見つける"」と「Google Maps で"行く"」の間を埋める、那須町特化の観光ルート提案アプリです。施設名や情報をいったん忘れ、**気になった写真だけで車のルートを設計する**のがコンセプト。ターゲットは画像で情報収集する若年層です。

新機能「**那須旅診断**」の流れ:

1. ユーザーが質問に答える（4軸 × 各4問の計16問）
2. 回答から **16タイプのいずれか**に分類される
3. **そのタイプのキャラクターイラストと、タイプに紐づいた写真**を提示する
4. そこから先は既存機能と同じく「**直感で写真を選んでルート設計**」へ繋がる

→ つまりキャラクターは「**診断結果を見た瞬間の主役ビジュアル**」です。結果画面で大きめに1枚出し、ユーザーが「これ、私だ」と愛着を持てることが狙い。診断選択肢や一覧で小さく並べることもあるため、**小サイズでもシルエットで違いがわかる**ことが望ましい。

### 制作上の前提（Claude Design 向けの補足）

- **診断結果画面はこれから作る新規ページ**です。既存の参照ビジュアルは、ルート設計画面（`/select`）の**スポットカード**（角丸16px・写真主体のカード）と、ホームの**ライン導線アイコン**（見る／記録／投稿。§5に実物の仕様）です。キャラクターはこれらと同じ画面世界に置かれるので、両者に馴染む線の質感・余白感にそろえてください。
- **キャラクターは「自分はこのタイプ」と思える楽しいラベル**という位置づけです。実際の写真推薦は連続的なスコアで動くため、1軸しか違わない隣りのタイプ同士では提示される写真がかなり近くなることがあります。つまり、**タイプの固有性はキャラクターが担う**設計です。だからこそ §5・§6 の「隣接タイプでも見分けがつく描き分け」が効いてきます。

## 2. 16タイプの作り方（4軸 × 各2分類 = 2⁴ = 16）

タイプは下の **4つの軸**それぞれを2択に振り分けて決まります。各軸に1文字コードを割り当て、4文字でタイプを表します（例: `PSNX`）。**この4文字コードをファイル名・性格表現の根拠にします。**

| 軸 | 分類A（コード） | 分類B（コード） |
|---|---|---|
| **行動** | 計画 `P`（Plan） | 即興 `I`（Improvise） |
| **欲求** | 刺激 `S`（Stimulate） | 癒し `H`（Heal） |
| **人** | 内向 `N`（iNtrovert） | 外向 `E`（Extrovert） |
| **価値の残し方** | 体験 `X`（eXperience） | 形 `F`（Form） |

> コード順は固定: **行動 → 欲求 → 人 → 価値**（`[P/I][S/H][N/E][X/F]`）。

### 各分類の「絵にするときの手がかり」（軸ごとの語彙）

題材（人物/マスコット/動物）が何であっても、**この語彙を組み合わせれば性格が伝わる**ように作ってください。

| 分類 | 表情・ポーズ | 小物・モチーフ |
|---|---|---|
| 計画 `P` | きちんとした構え・前を見据える | 地図、ルート線、手帳、チェックリスト |
| 即興 `I` | 風になびく・気まぐれな視線・寄り道する | 軽装、ふらりと歩く、矢印が分岐する |
| 刺激 `S` | 高揚した表情・動きのある躍動ポーズ | 山・絶景、スピード線、見上げる構図 |
| 癒し `H` | 穏やか・目を閉じる・くつろぐ | 湯けむり、お茶、植物、座る・寝そべる |
| 内向 `N` | 単独・横顔やうつむき・小物に集中 | ひとり、静かな間（ま）、囲われた空間 |
| 外向 `E` | 正面・笑顔・手を広げる・共有の所作 | 複数の影、手を振る、みんなで |
| 体験 `X` | 「何かをしている最中」（歩く/眺める/浸かる） | 動作が主役、足元・移動感 |
| 形 `F` | モノを持つ・撮る・集める | カメラ、お土産袋、スタンプ帳、コレクション |

> **軸ごとの「絵での出しやすさ」には差があります**（描き分けの優先度の目安）。
> - **欲求（刺激↔癒し）／価値（体験↔形）** は絵にしやすい（絶景↔湯けむり、動作中の身体↔カメラ・お土産）。**ここでシルエットの差を作るのが最優先。**
> - **人（内向↔外向）** は人数・正対/横顔で出せる。出しやすい。
> - **行動（計画↔即興）** が一番弱い。地図・手帳といった小物頼みになりがちなので、**姿勢（きちんと立つ↔ふらりと歩く・寄り道する）でも差を補強**してください。

## 3. 16タイプ一覧（性格と絵の方向性）

タイプ名は**仮称**です（最終的な日本語名はチームで詰めますが、性格の手がかりとして使ってください）。各行の「絵のヒント」は §2 の語彙の組み合わせです。

| # | コード | 仮称 | 性格（ひとことで） | 絵のヒント |
|---|---|---|---|---|
| 1 | `PSNX` | ひとり絶景ハンター | 綿密に計画し、刺激的な絶景をひとりで味わう | 地図を手に、ひとり高台で景色を見上げる |
| 2 | `PSNF` | 収集する探検家 | 計画的に名所を巡り、刺激を写真・記録で残す（単独） | 三脚／カメラ、スタンプ帳、ひとりで構える |
| 3 | `PSEX` | 冒険プランナー | みんなを率い、計画通りに刺激体験へ繰り出す | 地図を掲げ、仲間を先導するポーズ |
| 4 | `PSEF` | 思い出マイスター | 計画して、みんなで派手に盛り上がり記録に残す | 自撮り・お揃いグッズ、複数の影と笑顔 |
| 5 | `PHNX` | 静養の旅人 | 計画的にひとりで癒される体験（温泉・自然）に浸る | 湯けむりに目を閉じる、本／茶、静かな単独 |
| 6 | `PHNF` | 丁寧な蒐集家 | 計画的に、癒しのモノ（お土産・雑貨）を選び集める | お土産袋・押し花・手帳、落ち着いた単独 |
| 7 | `PHEX` | みんなで湯めぐり | 計画して、家族・友と癒し体験を共有する | 複数で湯けむり、和やかに並ぶ |
| 8 | `PHEF` | ほっこり記録係 | みんなで癒され、お土産・写真をまめに残す | みんなでお土産選び、穏やかな笑顔＋カメラ |
| 9 | `ISNX` | 気まぐれ探検家 | ふらりとひとり、行き当たりばったりで刺激を体験 | 軽装で寄り道、ひとり躍動、分岐する道 |
| 10 | `ISNF` | 直感コレクター | 即興で見つけた刺激を、その場で撮り集める（単独） | ふと立ち止まりシャッター、ひとり |
| 11 | `ISEX` | ノリで冒険隊 | みんなのノリで即興、刺激にダイブする | 駆け出す複数の影、勢いのある構図 |
| 12 | `ISEF` | 瞬間シェアラー | 即興でみんなと映える瞬間を作って共有する | 自撮り・SNS的ポーズ、複数で盛り上がる |
| 13 | `IHNX` | ゆるり散歩 | あてもなく、ひとりで癒しの時間を過ごす | のんびり歩く横顔、植物、ひとりの間 |
| 14 | `IHNF` | 小さな宝探し | 気ままに雑貨・カフェを巡り、好きなモノを持ち帰る | 雑貨を手に取る、カフェ、ひとり |
| 15 | `IHEX` | のんびり仲間旅 | 流れにまかせ、みんなで癒しの時間を共有する | 並んでくつろぐ複数、ゆるい笑顔 |
| 16 | `IHEF` | ほのぼの記録隊 | 気ままにみんなで、癒しの思い出をゆるく残す | みんなで写真、和やかな小物 |

> **隣接タイプは絵が似がちです**（1軸しか違わない組み合わせ）。たとえば `PHNX 静養の旅人` と `IHNX ゆるり散歩` は行動軸（計画↔即興）だけの違い。顔を統一しつつ小物だけで差を付けると、ほぼ見分けがつきません。こうしたペアは**姿勢・動きの差**（きちんと座って目を閉じる↔ふらりと歩く横顔）で描き分けてください。§6 の試作でこの描き分けを必ず検証します。

## 4. ビジュアル・アイデンティティ（必ず守る世界観）

イラストは下のデザイン言語に**完全に馴染む**必要があります。浮いて見えたら失敗です。
以下の HEX はアプリのソースで実際に使われている値です。

### 配色（このパレットの中だけで描く）

| 役割 | HEX | 用途 |
|---|---|---|
| 背景（生成り） | `#f7f5f0` | アプリ地（`--background`）。イラスト背景は**透過**にしてこの色に乗る前提 |
| 主線・本体（深緑） | `#2c3e2d` | 線画のメインの色（`--foreground`）。ほぼこれ1色で描く |
| 中間の緑 | `#5a7d5a` | 補助線・主役の小物など、少量のアクセント |
| やや明るい緑 | `#7d9a76` | アクセント（ブランドの「#」記号にも使用）。ごく少量 |
| 淡い緑 | `#8fa888` | さらに淡い補助・トーン落とし |
| もっとも淡い緑 | `#b6cbac` | ごく薄い面・ホバー縁など余白的なトーン |
| （任意の差し色）金 | `#c39a3e` | 使うとしてもごく一点。多用しない（実装では誘導ハイライトにのみ使用） |

- **基本は `#2c3e2d` 一色の線画**。緑の濃淡は「性格の主役になる小物1点」程度に絞る。**にぎやかな多色塗りはしない**（モノトーン指定）。
- 真っ黒（`#000`）・原色・寒色は使わない。すべて「森の緑」の範囲。
- 参考: スポットカードの写真プレースホルダは緑系（oklch、色相118〜182付近）のグラデーション。キャラがカードと並んでも色がぶつからないよう、この緑域に収める。

### 書体（参考・イラスト内に文字は基本入れない）

- 見出し: **Shippori Mincho**（明朝、太さ500–700）
- 本文: **Zen Kaku Gothic New**（ゴシック）
- イラスト内には文字を入れない方針（§7）。

### テクスチャ・形のことば

- 背景は**生成りの紙**。全面に**ごく薄い紙グレイン**（ノイズ）が乗っている（opacity 約 **4.5%**＝実装値 0.045）。イラスト自体にグレインは不要だが、紙の上に置かれる前提で**ベタ面は重くしない**。
- アプリには**有機的なブロブ（角の丸い不定形）**と**ゆらぐリング**が漂う（柔らかい radial-gradient の緑、リングの線は `rgba(90,125,90,.4)` 相当）。キャラの背景にモチーフを足すなら、この**有機ブロブ**が世界観と合う（四角い枠・幾何学グリッドは避ける）。
- UIは**角丸**が基調（ボタン・カードとも角丸。スポットカードは角丸16px）。線も**角を丸く**。

### ムードワード

> 静か / 余白 / 紙のあたたかみ / 森 / 上品 / 引き算 / 直感的 / 押しつけがましくない

## 5. 線画スタイルの作法（最重要・16種で統一）

アプリには既にラインアイコン群があり、これが**最も近い既存リファレンス**です。これに寄せてください。

### 既存アイコンの実物仕様（ソースで確認済み）

ホームの導線アイコン（見る／記録／投稿）と共通ナビは、すべて次の値で描かれています。

- **`viewBox="0 0 20 20"`**（20単位グリッド。※旧版にあった「24pxグリッド換算」は誤りで、実物は20単位です）
- **`stroke-width: 1.7`**、**`stroke-linecap: round` / `stroke-linejoin: round`**、**`fill: none`**
- 色は `currentColor`（実際の描画色は深緑 `#2c3e2d`、アクセントに `#5a7d5a`）
- 表示サイズは 17〜18px（CSSで可変。線幅も viewBox に対して相対）

実物のパス例（線の質感の基準。そのまま真似する必要はないが、この太さ・丸み・引き算の度合いに合わせる）:

```svg
<!-- カメラ（写真を投稿） -->
<rect x="2" y="6" width="16" height="11" rx="2.5"/>
<path d="M6.8 6l1.2-2h4l1.2 2"/>
<circle cx="10" cy="11.5" r="3"/>

<!-- 目（みんなの旅をみる） -->
<path d="M1.5 10S4.5 4 10 4s8.5 6 8.5 6-3 6-8.5 6-8.5-6-8.5-6Z"/>
<circle cx="10" cy="10" r="2.6"/>
```

### キャラ線画の指針

- **線幅は viewBox に対する比率で固定する**（絶対pxではなく比率で考える）。アイコンの比率は `1.7 / 20 = 約8.5%`。ただしキャラクターはアイコンより内部の線が多いため、同じ8.5%だと潰れて見える。**キャラはやや細めの約5%を採用**する。
- **具体的な作業値**: アートボードを **`viewBox="0 0 48 48"`** で作り、主線の **`stroke-width` は 2.5（48に対して約5.2%）で全16種固定**。小物などの補助線も同じ 2.5。表示サイズは CSS で可変（§7）。
  - 別の作業グリッドを使う場合も、**線幅 = 短辺の約5%** を守れば質感がそろう（例: 240アートボードなら stroke 12 前後）。**重要なのは16種すべてで同一値にすること。**
- `stroke-linecap` / `stroke-linejoin` は **round**、`fill` は基本 **none**（アイコンと同じ質感）。
- **塗りは最小限**。基本は線画＋ごく一部の面。影・グラデーション・立体陰影は**乗せない**（フラット）。
- **余白を大きく**取る。描き込みすぎない。引き算の絵。
- 線の角は丸く、有機的でやわらかいシルエット。とがった攻撃的な形にしない。

### 「統一するもの」と「変えるもの」（小サイズ判別との両立）

旧版は「変えるのは小物・ポーズ・表情だけ」としていましたが、それだと小サイズでの見分けが成立しません。次のように整理します。

- **全16種で必ず統一する**: 顔・目の描き方（同じキャラの別バリエーションに見えること）／線の太さ／画角（正方形）／キャラの基準スケール（並べたとき頭の高さ・足元が揃う）。
- **性格で積極的に変えてよい（むしろ変える）**: **ポーズ・姿勢・身体の向き**（立つ／座る／寝そべる／駆け出す／見上げる／うつむく）、表情、手にする小物、人数（単独／複数の影）。
- ねらい: **顔とタッチは「同じ家族」に見えるのに、シルエットだけで性格が伝わる**状態。サムネイルで「地図を掲げて前傾」と「湯に浸かって目を閉じる」が一目で違う、という水準を目指す。

## 6. 題材は3案で検証 → 1案に決定（進め方）

題材（キャラが「何」か）は未決定です。**まず比較検証用の試作**をお願いします。

### フェーズ1: 試作（各案で「遠いタイプ3体」＋「近いタイプ2体」）

下の3案それぞれで、まず性格差が大きい3タイプを試作し、**加えて1軸しか違わない近接ペアも1組**必ず試作してください。近接ペアが描き分けられるかが、16種フルセットが成立するかの分かれ目です。

- **遠いタイプ3体（軸が大きく異なる）**: `PSEX 冒険プランナー`／`PHNX 静養の旅人`／`ISEF 瞬間シェアラー`
- **近接ペア2体（行動軸だけ違う最難ケース）**: `PHNX 静養の旅人`（↑と共用可）と `IHNX ゆるり散歩`
  - この2体が、姿勢・動きの差で見分けられるかを確認する。ここが曖昧なら、計画↔即興の絵の語彙を見直す。

| 案 | 内容 | 期待 / 懸念 |
|---|---|---|
| **A. 人物（旅人）** | 性別を限定しない、那須を旅する人のシルエット／線画。服装・持ち物・ポーズで性格を出す | 最も汎用的。16種の差を付けやすい |
| **B. オリジナルのマスコット** | #NASU の世界観に合う架空のキャラ（精霊・小さな旅の妖精など） | ブランドの顔になり愛着を作りやすい。難度は高め |
| **C. 動物モチーフ** | 那須らしい動物をキャラ化 | 親しみやすい。16タイプの性格差を表現しづらい懸念あり。**※既存施設の公式マスコットやロゴは使わない。那須らしい動物をモチーフにした完全オリジナルにとどめる** |

### フェーズ2: 決定 → 共通素体 → フルセット

1. 3案の試作（近接ペア込み）を見てチームで1案に決定。
2. **共通素体（モデルシート）を1枚先に確定**する。決定案の「同じ顔・同じ目・同じ体・同じ線幅」のニュートラルな基準1体を作り、これを全16種の土台にする。
   - 16種を別々に描き起こすと顔や線の質感が必ずズレる。**素体を固定し、ポーズ・小物・表情だけを差し替えて派生**させることで、統一感を仕組みで担保する。
3. 素体から **16種すべて**を、§3 の性格・§5 の作法・§7 の仕様に沿って制作。

## 7. 納品仕様

| 項目 | 指定 |
|---|---|
| 形式 | **SVG**（パスベース。背景は完全透過 `transparent`） |
| 作業アートボード | **正方形 `viewBox="0 0 48 48"`**（§5）。全16種で同一画角・同一マージン。表示サイズは CSS 可変 |
| 表示の目安 | 結果画面で大きめ（例 160px 前後）＋一覧/選択肢で小さく（例 40〜56px）。**小サイズでもシルエットで違いが読める**こと |
| キャラの大きさ | 全16種で**同じスケール・同じ基準線**に揃える（並べたとき頭の高さ・足元が揃う） |
| 色 | §4 のパレットのみ。基本 `#2c3e2d`＋緑の濃淡を少量。可能なら `currentColor` ベースにして CSS で色を当てられると望ましい |
| 線 | §5 の均一・丸端の線。**stroke-width は 2.5（48グリッド）で全種共通** |
| 文字 | イラスト内に文字を入れない |
| ファイル名 | **`type-[コード].svg`**（例: `type-PSNX.svg`, `type-IHEF.svg`）。§2 の4文字コードを使う |
| 命名一覧 | `PSNX PSNF PSEX PSEF PHNX PHNF PHEX PHEF ISNX ISNF ISEX ISEF IHNX IHNF IHEX IHEF` の16ファイル |

- SVGは余計なメタデータを除き、`viewBox` 付き・`width/height` 非依存（CSSでサイズ可変）にしてください。

## 8. やってほしいこと / 避けてほしいこと

**やってほしい**
- 深緑モノトーンの、静かで上品な線画（既存アイコンと同じ丸端・単一線幅・引き算の質感）
- 16種で統一された顔・目・線幅・画角・基準スケール
- 性格は「**ポーズ・姿勢**・小物・表情」で表現（§2の語彙、§5の整理）
- 隣接タイプ（1軸違い）でも姿勢・動きの差で見分けがつくこと
- 角丸・有機的なやわらかいシルエット
- 透過SVG、小サイズでも判別できるシルエット
- 共通素体を先に固定し、そこから差分で16種を派生（§6）

**避けてほしい**
- にぎやかな多色塗り・原色・黒ベタ
- 立体的な陰影・グラデーション・写実的な描き込み
- 四角い枠・幾何学グリッド・かっちりした囲み（世界観は有機的）
- 16種でバラバラな画角・線の太さ・キャラの大きさ
- 性別・年齢を限定しすぎる表現（人物案の場合）
- 顔・小物だけで差を付け、姿勢を全種同じにすること（小サイズで見分けられなくなる）
- 既存施設の公式マスコット・ロゴの模倣（動物案）
